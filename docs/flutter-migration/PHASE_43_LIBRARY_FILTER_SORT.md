# Phase 43：Library Date Filter + Sorting

## 书架

书架升级为三页：

- 本地收藏
- 历史
- 账户收藏

默认排序为 **收藏时间**，符合参考图。

排序弹窗提供：

- 收藏时间
- 发布时间
- 日期选择器
- 清除日期
- 重置 / 取消 / 确定

## 数据语义

新增 Drift `library_entries.favorited_at`：

- 新收藏记录真实收藏发生时间。
- schema 从 v1 升至 v2。
- 旧的已收藏项目将以已有 `last_opened_at` 回填，无法恢复时保持 null。
- 本地收藏按收藏时间或发布时间排序。
- 日期筛选根据当前排序选择的时间字段执行。
- 历史按打开时间筛选和排序。

## 账户收藏

登录后账户收藏显示在书架第三页，支持选择服务端收藏夹。日期筛选按可用发布时间过滤；收藏时间在站点返回未提供时不伪造，保持服务器列表顺序。

## 注意

数据库 schema v2 需要 Drift codegen 和迁移测试。正式发布前必须通过 CI 验证升级路径。
